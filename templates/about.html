About StudentPredictor AI

A production-grade ML application predicting academic performance using state-of-the-art machine learning algorithms.

🎯 Project Objective

Student Performer Predictor is a machine learning web application that analyzes key academic indicators to predict whether a student is likely to be a High, Average, or Low performer.

The system trains on a dataset of 1,000 synthetic student records and evaluates four different ML models, automatically selecting the best-performing one for predictions.

🧠 How It Works

  1. Student data is collected via an intuitive web form
  2. Input features are preprocessed (normalized, encoded)
  3. The best-trained ML model makes a prediction
  4. A confidence score and personalized advice are returned

📊 Models Compared

  • Logistic Regression
  • Decision Tree Classifier
  • Random Forest Classifier ← typically best
  • Support Vector Classifier (SVC)
